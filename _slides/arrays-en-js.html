Métodos de arrays

--- #
Añadir elementos Estos métodos sirven para **insertar nuevos elementos** en un array, ya sea al inicio o al final, modificando el array original. --- # Push El método `.push()` agrega un nuevo elemento al final del arreglo y modifica el original. ### Ejemplo -- PUSH UNSHIFT ## Agregar al final En el siguiente ejemplo agregaremos nuevos héroes al final del arreglo usando `.push()`. ```javascript const heroesDC = ["batgirl", "green arrow"]; console.log(heroesDC); heroesDC.push("catwoman", "shazam"); console.log(heroesDC); ```
--- # Unshift El método `.unshift()` agrega uno o más elementos al inicio del arreglo y modifica el original. ### Ejemplo -- UNSHIFT ELIMINAR ## Agrega al inicio En el siguiente ejemplo agregaremos nuevos jugadores al inicio del equipo usando `.unshift()`. ```javascript const equipo = ["Messi", "Suárez"]; console.log(equipo); equipo.unshift("Neymar", "Iniesta"); console.log(equipo); ```
--- #
Eliminar elementos Se utilizan para __remover elementos existentes__, ya sea al inicio, final o en posiciones específicas. --- # Pop El método `.pop()` elimina el último elemento del arreglo y modifica el original. ### Ejemplo -- POP SHIFT ## Eliminar el último En el siguiente ejemplo eliminaremos el último jugador del equipo usando `.pop()`. ```javascript const equipo = ["Messi", "Suárez", "Neymar"]; console.log(equipo); equipo.pop(); console.log(equipo); ```
--- # Shift El método `.shift()` elimina el primer elemento del arreglo y desplaza los demás elementos hacia atrás. ### Ejemplo -- SHIFT FILTRAR Y BUSCAR ## Eliminar el primero En el siguiente ejemplo eliminaremos la primera tarea del arreglo y veremos cómo cambian sus índices. ```js const tareas = ["Despertar", "Desayunar", "Estudiar", "Dormir"]; console.log(Object.entries(tareas)); tareas.shift(); console.log(Object.entries(tareas)); ```
--- #
Filtrar y buscar Permiten consultar información dentro del array sin modificarlo directamente (o creando nuevos resultados). --- ## Includes El método `.includes()` verifica si un valor existe dentro de un arreglo o una cadena de texto, devolviendo `true` si lo encuentra y `false` si no está presente. -- INCLUDES INDEXOF ## Verifica si un elemento existe En el siguiente ejemplo comprobamos si una fruta está dentro del arreglo usando `.includes()`. ```js const frutas = ["manzana", "plátano", "naranja"]; console.log(frutas.includes("plátano")); console.log(frutas.includes("uva")); ```
--- # indexOf El método `.indexOf()` devuelve la posición (índice) de la primera aparición de un elemento dentro de un arreglo o cadena de texto, o `-1` si no lo encuentra. -- INDEXOF FIND ## Conocer la posición En el siguiente ejemplo buscamos la posición de dos equipos dentro del arreglo usando `.indexOf()` y vemos el índice que devuelve en consola. ```javascript const equipos = ["Colo Colo", "U de Chile", "Universidad Católica", "O'Higgins"]; console.log(equipos.indexOf("Universidad Católica")); console.log(equipos.indexOf("Palestino")); ```
--- # FIND El método `.find()` devuelve el primer elemento de un arreglo que cumpla con una condición, o `undefined` si no encuentra ninguno. -- FIND FILTER ## Buscar el primero En el siguiente ejemplo buscamos el primer número que sea mayor o igual a 18 dentro del arreglo usando `.find()` y mostramos el resultado en consola. ```javascript const edades = [12, 18, 25, 17, 30]; const mayorEdad = edades.find(edad => edad >= 18); console.log(mayorEdad); ```
--- # Filter El método `.filter()` crea un nuevo arreglo con los elementos que cumplen una condición ### Ejemplo -- FILTER TRANSFORMAR Y RECORRER ## Filtrar por condición En el siguiente ejemplo usamos `.filter()` para obtener un nuevo arreglo con solo los números pares, redondeando cada valor antes de evaluarlo. ```js const numbers = [10, 20, 55.33, 23]; function numberIsEven(num) { return Math.round(num) % 2 === 0; } const pares = numbers.filter(numberIsEven); console.log(pares); ```
--- #   
Transformar y recorrer --- # Map El método `.map()` crea un nuevo arreglo aplicando una función a cada elemento del arreglo original, transformando sus valores sin modificar el arreglo inicial. -- MAP FOREACH ## Un nuevo array transformando En el siguiente ejemplo transformamos un arreglo de nombres de jedis en frases sobre el uso de la Fuerza usando `.map()` y mostramos el resultado en consola. ```javascript const jedis = ["Anakin", "Luke", "Rey"]; const ladosFuerza = jedis.map(jedi => `${jedi} usa la Fuerza`); console.log(ladosFuerza); ```
--- # Foreach El método `.forEach()` recorre cada elemento de un arreglo y ejecuta una función para cada uno, sin crear un nuevo arreglo. -- FOREACH REDUCE ## Recorrer cada elemento En el siguiente ejemplo recorremos un arreglo de héroes usando `.forEach()` y mostramos cada elemento en consola. ```javascript const heroes = ["Iron Man", "Thor", "Hulk"]; heroes.forEach(hero => { console.log(hero); }); ```
--- # Reduce El método `.reduce()` recorre un arreglo y lo reduce a un solo valor acumulando resultados en cada iteración. -- REDUCE ORDENAR ## Reducir todo a un valor acumulado En el siguiente ejemplo sumamos todos los números de un arreglo usando `.reduce()` y mostramos el resultado en consola. ```javascript id="reduce1" const numeros = [10, 20, 30, 40]; const suma = numeros.reduce((acumulador, numero) => { return acumulador + numero; }, 0); console.log(suma); ```
--- #
Ordenar --- # Sort El método `.sort()` se utiliza para ordenar los elementos de un arreglo, ya sea en orden alfabético o numérico, modificando el arreglo original según una función de comparación o el orden Unicode por defecto. -- ## Ordenar de mayor a menor En el siguiente ejemplo ordenamos un arreglo de números de mayor a menor usando `.sort()` y mostramos el resultado en consola. ```javascript const numeros = [5, 120, 12, 1, 45]; numeros.sort((a, b) => b - a); console.log(numeros); ```
