¿Qué es una Promesa?

Promise es un objeto que proporciona una construcción útil cuando se trabaja con tareas asincrónicas.

```js [1-18] run // Crear una promesa const promesa = new Promise((resolve, reject) => { setTimeout(() => { if (true) { resolve({ status: 200, ok: true, message: "Inicio de sesión exitoso", }); } else { reject({ status: 401, ok: false, message: "Credenciales inválidas", }); } }, 1000); }); ```
¿Qué ocurre aquí? Se crea una promesa que simula un inicio de sesión tras 1 segundo. Todas las promesas, manejan dos funciones: - __`resolve()`__: se ejecuta si todo sale bien (retorna 200 OK) - __`reject()`__: se ejecuta si hay error (retorna 401 Unauthorized)
---

¿Cómo se consume una promesa?

Una de las primeras formas de trabajar con promesas es mediante __`.then()`__ y __`.catch()`__, que permiten gestionar respuestas exitosas y errores de manera asíncrona.
```js run // Consumir una promesa promesa .then((respuesta) => { console.log(respuesta.status); console.log(respuesta.message); }) .catch((error) => { console.error(error.status); console.error(error.message); }); ````
¿Qué ocurre aquí? Una vez creada la promesa, podemos manejar con __.then()__ los casos exitosos y __.catch()__ para capturar posibles errores durante la ejecución.
---

Enfoque moderno con async/await

Una forma más moderna de trabajar con promesas es mediante async y await, lo que permite escribir código asíncrono de manera más fácil.

```js // Consumir una promesa async function iniciarSesion() { try { const respuesta = await promesa; console.log(respuesta.status); console.log(respuesta.message); } catch (error) { console.error(error.status); console.error(error.message); } } ```
¿Qué ocurre aquí? La palabra clave __await__ espera el resultado de la promesa. Si ocurre un error, este puede gestionarse fácilmente mediante un bloque __try/catch__.

Servicios

El módulo api.js centraliza las peticiones a la API para obtener y gestionar personajes. Tenemos la siguiente función para configurar la URL de la API y realizar la petición con fetch() y manejamos la paginación por parámetro.

```js run const API_BASE_URL = "https://rickandmortyapi.com/api"; export async function getCharacters(page = 1) { try { const url = `${API_BASE_URL}/character?page=${page}`; const response = await fetch(url); if (!response.ok) { throw new Error(`Error HTTP: ${response.status}`); } const datos = await response.json(); return datos.results; } catch (error) { console.error("Error al obtener personajes:", error); return null; } } ``` --
