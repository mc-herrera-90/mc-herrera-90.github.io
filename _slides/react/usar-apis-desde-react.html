¿Qué es una Promesa?

__`Promise`__ es un objeto que proporciona una construcción útil cuando se trabaja con tareas asincrónicas.
```js // Crear una promesa const promesa = new Promise((resolve, reject) => { setTimeout(() => { if (true) { resolve({ status: 200, ok: true, message: "Inicio de sesión exitoso", }); } else { reject({ status: 401, ok: false, message: "Credenciales inválidas", }); } }, 1000); }); ````
¿Qué ocurre aquí?
Esta promesa simula un inicio de sesión. Tras 1 segundo, ejecuta __resolve()__ con una respuesta __200 OK__ o __reject()__ con un error __401 Unauthorized__, representando el comportamiento asíncrono de una API.
---

¿Cómo se consume una promesa?

Una de las primeras formas de trabajar con promesas es mediante __`.then()`__ y __`.catch()`__, que permiten gestionar respuestas exitosas y errores de manera asíncrona.
```js // Consumir una promesa promesa .then((respuesta) => { console.log(respuesta.status); console.log(respuesta.message); }) .catch((error) => { console.error(error.status); console.error(error.message); }); ````
¿Qué ocurre aquí?
Una vez creada la promesa, podemos manejar con __.then()__ los casos exitosos y __.catch()__ para capturar posibles errores durante la ejecución.
---

Enfoque moderno con async/await

Una forma más moderna de trabajar con promesas es mediante __`async`__ y __`await`__, lo que permite escribir código asíncrono de manera más clara y fácil de entender.
```js // Consumir una promesa async function iniciarSesion() { try { const respuesta = await promesa; console.log(respuesta.status); console.log(respuesta.message); } catch (error) { console.error(error.status); console.error(error.message); } } iniciarSesion(); ```
¿Qué ocurre aquí?
La palabra clave __await__ espera el resultado de la promesa. Si ocurre un error, este puede gestionarse fácilmente mediante un bloque __try/catch__.
