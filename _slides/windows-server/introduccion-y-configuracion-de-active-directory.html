¿Qué es Active Directory?

Active Directory ( AD ) es un servicio de directorio que permite administrar de forma centralizada identidades, accesos y recursos dentro de una organización. En entornos corporativos, suele utilizarse junto con Active Directory Domain Services ( AD DS ), encargado de la gestión de dominios, usuarios, equipos y políticas de seguridad.
