Instalación en Ubuntu

-- ### Pasos de ejecución en orden
1Preparar el sistema
```bash sudo apt update && sudo apt install gnupg curl -y ```
2Importar la llave GPG pública
```bash curl -fsSL https://www.mongodb.org/static/pgp/server-8.0.asc | \ sudo gpg -o /usr/share/keyrings/mongodb-server-8.0.gpg \ --dearmor ```

3Agregar el repositorio
```bash echo "deb [ arch=amd64,arm64 signed-by=/usr/share/keyrings/mongodb-server-8.0.gpg ] \ https://repo.mongodb.org/apt/debian \ bookworm/mongodb-org/8.0 main" | \ sudo tee /etc/apt/sources.list.d/mongodb-org-8.0.list ```
4Actualizar e instalar
```bash sudo apt update sudo apt install -y mongodb-org ```
--
