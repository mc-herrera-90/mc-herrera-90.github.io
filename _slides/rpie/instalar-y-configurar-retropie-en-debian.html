> __Con cualquiera de estas distribuciones instaladas__, ya podemos continuar con la instalación de RetroPie. Presiona → para continuar ---
> **Ojo**: El script de RetroPie para Debian **solo funciona en sistemas x86** (**32** y **64 bits**). Si usas un equipo ARM, deberás ejecutar una máquina virtual **x86**; en una máquina virtual ARM no funcionará.

Realiza los siguientes pasos en la Terminal

> Recuerda abrir la Terminal con: > > Ctrl + Alt + T
Presiona → para continuar --- 1. Actualiza el sistema {% include terminal-pixel.html command="sudo apt update && sudo apt upgrade -y" %} 2. Instala los paquetes necesarios {% include terminal-pixel.html command="sudo apt install -y git dialog unzip xmlstarlet" %} 3. Descarga el script de configuración de RetroPie {% include terminal-pixel.html command="git clone --depth=1 https://github.com/RetroPie/RetroPie-Setup.git" %} 4. Ingresa a la carpeta y ejecuta el instalador {% include terminal-pixel.html command="cd RetroPie-Setup && sudo ./retropie_setup.sh" %} Presiona → para continuar --- > El script comenzará a ejecutarse e instalará paquetes adicionales, tras unos breves momentos, aparecerá el menú como se muestra a continuación. {% assign imagenes = site.static_files | where_exp: "item", "item.path contains '/assets/media/rpie/run-script-setup/'" %} {% capture grid %}

{% endcapture %} {{ grid | strip_newlines }} > El proceso puede tardar entre 20 y 30 minutos, dependiendo del hardware y la conexión a internet. Presiona → para continuar --- > Una vez finalizada la instalación, el sistema regresará al menú principal del script. En ese momento, simplemente cierra la ventana y busca __rpie__ (o ejecuta __emulationstation__ desde la terminal). ---
