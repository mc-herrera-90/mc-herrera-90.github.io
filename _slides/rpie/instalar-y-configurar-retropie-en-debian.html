Tener una Distribución basada en Debian

Lubuntu

18.04 LTS +

Ubuntu

18.04 LTS +

Linux Mint

20 LTS +

Con cualquiera de estas distribuciones instaladas, ya podemos continuar con la instalación de RetroPie. ---

Realiza los siguientes pasos en la Terminal

1. Actualiza el sistema {% include terminal-pixel.html command="sudo apt update && sudo apt upgrade -y" %} 2. Instala los paquetes necesarios {% include terminal-pixel.html command="sudo apt install -y git dialog unzip xmlstarlet" %} 3. Descarga el script de configuración de RetroPie {% include terminal-pixel.html command="git clone --depth=1 https://github.com/RetroPie/RetroPie-Setup.git" %} 4. Ingresa a la carpeta y ejecuta el instalador {% include terminal-pixel.html command="cd RetroPie-Setup && sudo ./retropie_setup.sh" %} --- El script comenzará a ejecutarse e instalará paquetes adicionales, tras unos breves momentos, aparecerá el menú como se muestra a continuación:
