Añadir elementos

Estos métodos sirven para **insertar nuevos elementos** en un array, ya sea al inicio o al final, modificando el array original.

--

PUSH: Agregar al final

Este método agrega uno o más elementos al final del array y modifica el original.

Ejemplo:

```javascript [1,3,5,7] run const mascotas = ["🐶", "🐱"]; console.log("Antes:", mascotas); mascotas.push("🐰", "🐹"); console.log("Después:", mascotas); ```
["🐶","🐱"].push("🐰","🐹") + ➡️ 🐰🐹 ["🐶", "🐱","🐰", "🐹"]
{% include reveal/navigate.html down="UNSHIFT" next="ELIMINAR" %}
--

UNSHIFT: Agregar al inicio

Este método agrega uno o más elementos al inicio del array y modifica el original.

Ejemplo:

```javascript [1,3,5,7] run const planetas = ["🌍", "🪐"]; console.log("Antes:", planetas); planetas.unshift("☀️", "🌕"); console.log("Después:", planetas); ```
["🌍","🪐"].unshift("☀️","🌕") + ☀️🌕 ⬅️ ["☀️","🌕","🌍", "🪐"]
{% include reveal/navigate.html up="PUSH" next="ELIMINAR" %}

Eliminar elementos

Se utilizan para __remover elementos existentes__, ya sea al inicio, final o en posiciones específicas.

--

POP: Eliminar el último

Este método elimina el último elemento del array y modifica el original.

Ejemplo:

```javascript [] run const carrito = ["🍎", "🥛", "🍞"]; console.log("Antes:", carrito); const eliminado = animales.pop(); console.log("Eliminado:", eliminado); console.log("Después:", carrito); ```
["🍎", "🥛", "🍞"].pop() ❌ 🍞 ["🍎", "🥛"]
{% include reveal/navigate.html down="SHIFT" next="FILTRAR Y BUSCAR" %}
--

SHIFT: Eliminar el primero

Este método elimina el primer elemento del array y desplaza los demás elementos hacia atrás.

Ejemplo:

```js [] run const animales = ["🐶", "🐱", "🐰"]; console.log("Antes:", animales); const eliminado = animales.shift(); console.log("Eliminado:", eliminado); console.log("Después:", animales); ```
["🐶","🐱","🐰"].shift() ❌ 🐶 ["🐱","🐰"]
{% include reveal/navigate.html up="POP" down="SPLICE" next="FILTRAR Y BUSCAR" %}
--

SPLICE: Eliminar por posición

Este método elimina uno o varios elementos del array indicando la posición inicial y la cantidad de elementos que se eliminarán.

Ejemplo:

```js [] run const animales = ["🐶", "🐱", "🐰"]; console.log("Antes:", animales); const eliminado = animales.splice(1, 1); console.log("Eliminado:", eliminado); console.log("Después:", animales); ```
["🐶","🐱","🐰"].splice(1, 1) ❌ 🐱 ["🐶","🐰"]
["🐶","🐱","🐰"].splice(1) ❌ 🐱🐰
Si no se indica la cantidad, se eliminarán todos desde esa posición

Filtrar y buscar

Permiten consultar información dentro del array sin modificarlo directamente o creando nuevos resultados.

--

INCLUDES: Verificar existencia

Este método verifica si un valor existe dentro de un array o una cadena de texto, devolviendo true si lo encuentra y false si no está presente.

Ejemplo:

```js [1,3-5,7-9] run const frutas = ["🍎", "🍌", "🍇", "🍍"]; const existePlatano = frutas.includes("🍌"); const existeUva = frutas.includes("🍇"); const existeMango = frutas.includes("🥭"); console.log("🍌 ❓", existePlatano); console.log("🍇 ❓", existeUva); console.log("🥭 ❓", existeMango); ```
["🍎", "🍌", "🍇", "🍍"] 🔎 🍌 .includes(🍌) ✅ 🔎 🍇 .includes(🍇) ✅ 🔎 🥭 .includes(🥭) ❌
{% include reveal/navigate.html down="INDEXOF" next="TRANSFORMAR" %}
--

INDEXOF: Conocer la posición

Este método devuelve la posición ( índice ) de la primera aparición de un elemento dentro del array o cadena de texto, o `-1` si no lo encuentra. ### Ejemplo
```javascript run const animales = ["🐶", "🐱", "🐭", "🐹", "🐰"]; const indicePerro = animales.indexOf("🐶"); const indiceGato = animales.indexOf("🐱"); const indiceLeon = animales.indexOf("🦁"); console.log(indicePerro); // 0 console.log(indiceGato); // 1 console.log(indiceLeon); // -1 ```
En el ejemplo buscamos la posición de los animales dentro del array usando .indexOf() y vemos el resultado en consola.
{% include reveal/navigate.html up="INCLUDES" down="FIND" next="TRANSFORMAR" %}
--

FIND: Buscar el primer match

Este método devuelve el primer elemento de un array que cumpla con una condición, o `undefined` si no encuentra ninguno. ### Ejemplo
```javascript [] run const productos = [ { nombre: "⌨️ Teclado", stock: 0 }, { nombre: "🖱️ Mouse", stock: 5 }, { nombre: "🖥️ Monitor", stock: 3 }, { nombre: "🎧 Audífonos", stock: 10 } ]; // buscar el primer producto con stock disponible const disponible = productos.find(p => p.stock > 0); console.log(disponible.nombre, "➡️", disponible.stock); ```
En el ejemplo buscamos el primer producto con stock mayor a 0 dentro del array usando .find() y mostramos el resultado en consola.
{% include reveal/navigate.html up="INDEXOF" down="FILTER" next="TRANSFORMAR" %}
--

FILTER: Buscar todos los match

Este método crea un nuevo array con los elementos que cumplen una condición. ### Ejemplo
```js run const numbers = [10, 20, 55.33, 23]; function numberIsEven(num) { return Math.round(num) % 2 === 0; } const pares = numbers.filter(numberIsEven); console.log(pares); ```
En el siguiente ejemplo usamos .filter() para obtener un nuevo arreglo con solo los números pares, redondeando cada valor antes de evaluarlo.

Transformar y recorrer

Estos métodos permiten recorrer los elementos de un array, transformarlos y generar nuevos arreglos o resultados mediante funciones de procesamiento.

--

MAP: Crear un nuevo array

El método `.map()` crea un nuevo array aplicando una función a cada elemento del array original, transformando sus valores sin modificar el original. ### Ejemplo
```javascript run const nombresJedi = ["Anakin", "Luke", "Rey"]; // Crear un nuevo arreglo agregando un texto a cada nombre const mensajesJedi = nombresJedi.map((nombreJedi) => { return `${nombreJedi} usa la Fuerza`; }); // Mostrar el nuevo arreglo en la consola console.log(mensajesJedi); ```
En el ejemplo usamos un array de nombres y creamos uno nuevo usando .map().
FOREACH ORDENAR
--

FOREACH: Recorrer un array

El método `.forEach()` recorre cada elemento de un arreglo y ejecuta una función para cada uno, sin crear un nuevo arreglo. ### Ejemplo
```javascript run const heroes = ["Iron Man", "Thor", "Hulk"]; // Recorrer cada elemento del arreglo heroes.forEach(hero => { console.log(hero); }); ```
En el ejemplo recorremos el array de héroes usando .forEach() y mostramos cada elemento en consola.
MAP REDUCE ORDENAR

REDUCE: Reducir todo a un valor acumulado

El método `.reduce()` recorre un array y lo reduce a un solo valor acumulando resultados en cada iteración.
```javascript run const numeros = [10, 20, 30, 40]; const suma = numeros.reduce((acumulador, numero) => { return acumulador + numero; }, 0); console.log(suma); ```
En el siguiente ejemplo sumamos todos los números de un arreglo usando `.reduce()` y mostramos el resultado en consola.
