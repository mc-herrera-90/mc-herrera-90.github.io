Métodos estáticos

Estos métodos pertenecen a la clase Array, por lo que se utilizan directamente como Array.metodo() y no sobre un array existente. Permiten crear arrays o comprobar si un valor es un array.

--

Array.isArray(valor):Boolean
· Comprobar si es un array ·

> Usa `Array.isArray()` para comprobar arrays > > 
> if (Array.isArray(valor)) {
>    valor.forEach(item => console.log(item));
> }

· Playground ·

```js [] run const valor = ["🍎", "🍌", "🍇"]; if (Array.isArray(valor)) { console.log("Es un array."); valor.forEach(item => console.log(item)); } else { console.log("No es un array."); } ``` {% include reveal/console.html id="demo" %}
--

Array.from(iterable):Array
· Crear un array desde un iterable ·

> Convierte un iterable en un array real. > > 
> const letras = Array.from("JS");
> letras.forEach(l => console.log(l));

· Playground ·

```js [] run const a = Array.from("JS"); const b = Array.from({ length: 5 }, (_, i) => i + 1); console.log(a); console.log(b); ```
{% include reveal/console.html id="Arrayfrom" %}

Eliminar elementos

Se utilizan para __remover elementos existentes__, ya sea al inicio, final o en posiciones específicas.

--

POP: Eliminar el último

Este método elimina el último elemento del array y modifica el original.

Ejemplo:

```javascript [] run const carrito = ["🍎", "🥛", "🍞"]; console.log("Antes:", carrito); const eliminado = animales.pop(); console.log("Eliminado:", eliminado); console.log("Después:", carrito); ```
{% include reveal/navigate.html down="SHIFT" next="FILTRAR Y BUSCAR" %}
["🍎", "🥛", "🍞"] {% include icon/pixel-plus.svg %} .pop() {% include icon/pixel-plus.svg %} ❌ 🍞 {% include icon/pixel-plus.svg %} ["🍎", "🥛"]
--

SHIFT: Eliminar el primero

Este método elimina el primer elemento del array y desplaza los demás elementos hacia atrás.

Ejemplo:

```js [] run const animales = ["🐶", "🐱", "🐰"]; console.log("Antes:", animales); const eliminado = animales.shift(); console.log("Eliminado:", eliminado); console.log("Después:", animales); ```
{% include reveal/navigate.html up="POP" down="SPLICE" next="FILTRAR Y BUSCAR" %}
["🐶", "🐱", "🐰"]. {% include icon/pixel-plus.svg %} .shift() {% include icon/pixel-plus.svg %} ❌ 🐶 {% include icon/pixel-plus.svg %} ["🐱","🐰"]
--

SPLICE: Eliminar por posición

Este método elimina uno o varios elementos del array indicando la posición inicial y la cantidad de elementos que se eliminarán.

Ejemplo:

```js [] run const animales = ["🐶", "🐱", "🐰"]; console.log("Antes:", animales); const eliminado = animales.splice(1, 1); console.log("Eliminado:", eliminado); console.log("Después:", animales); ```
{% include reveal/navigate.html up="SHIFT" next="FILTRAR Y BUSCAR" %}
["🐶" ,"🐱", "🐰"] {% include icon/pixel-plus.svg %} .splice(1, 1) {% include icon/pixel-plus.svg %} ❌ 🐱 {% include icon/pixel-plus.svg %} ["🐶", "🐰"]
["🐶","🐱","🐰"].splice(1) ❌ 🐱🐰
Si no se indica la cantidad, se eliminarán todos desde esa posición

Filtrar y buscar

Permiten consultar información dentro del array sin modificarlo directamente o creando nuevos resultados.

--

INCLUDES: Verificar existencia

Este método verifica si un valor existe dentro de un array o una cadena de texto, devolviendo true si lo encuentra y false si no está presente.

Ejemplo:

```js [1,3-5,7-9] run const frutas = ["🍎", "🍌", "🍇", "🍍"]; const existePlatano = frutas.includes("🍌"); const existeUva = frutas.includes("🍇"); const existeMango = frutas.includes("🥭"); console.log("🍌 ❓", existePlatano); console.log("🍇 ❓", existeUva); console.log("🥭 ❓", existeMango); ```
{% include reveal/navigate.html down="INDEXOF" next="TRANSFORMAR" %}
["🍎", "🍌", "🍇", "🍍"] {% include icon/pixel-plus.svg %} 🔎 🍌 .includes(🍌) ✅ {% include icon/pixel-plus.svg %} 🔎 🍇 .includes(🍇) ✅ {% include icon/pixel-plus.svg %} 🔎 🥭 .includes(🥭) ❌
--

INDEXOF: Conocer la posición

Este método devuelve la posición ( índice ) de la primera aparición de un elemento dentro del array o cadena de texto, o __-1__ si no lo encuentra.

Ejemplo:

```javascript run const animales = ["🐶", "🐱", "🐭", "🐹", "🐰"]; const indicePerro = animales.indexOf("🐶"); const indiceGato = animales.indexOf("🐱"); const indiceLeon = animales.indexOf("🦁"); console.log(indicePerro); // 0 console.log(indiceGato); // 1 console.log(indiceLeon); // -1 ```
{% include reveal/navigate.html up="INCLUDES" down="FIND" next="TRANSFORMAR" %}

--

FIND: Buscar el primer match

Este método devuelve el primer elemento de un array que cumpla con una condición, o __undefined__ si no encuentra ninguno.

Ejemplo:

```javascript [] run const productos = [ { item: "⌨️", stock: 0 }, { item: "🖱️", stock: 5 }, { item: "🖥️", stock: 3 } ]; const disponible = productos.find(p => p.stock > 0 ); console.log("Primer match:", disponible); ```
{% include reveal/navigate.html up="INDEXOF" down="FILTER" next="TRANSFORMAR" %}
[ { item:"⌨️", stock: 0 }, { item:"🖱️", stock: 5 }, { item:"🖥️", stock: 3 } ] {% include icon/pixel-plus.svg %} .find(i => i.stock > 0) {% include icon/pixel-plus.svg %} { item:"⌨️", stock: 0 } ❌ { item:"🖱️", stock: 5 } ✅
--

FILTER: Buscar todos los match

Este método crea un nuevo array con los elementos que cumplen una condición.

Ejemplo:

```js [] run const numeros = [10, 20, 55, 23]; function esPar(num) { return num % 2 === 0; } const pares = numbers.filter(esPar); console.log(pares); ```

Transformar y recorrer

Estos métodos permiten recorrer los elementos de un array, transformarlos y generar nuevos arreglos o resultados mediante funciones de procesamiento.

--

MAP: Crear un nuevo array

Este método crea un nuevo array aplicando una función a cada elemento del array original, transformando sus valores sin modificar el original.

Ejemplo:

```javascript [] run const jedis = ["Anakin", "Luke", "Rey"]; // asignar sable const conSable = jedis.map(jedi => { return `${jedi} usa ⚔️` }); console.log(conSable); ```
{% include reveal/navigate.html down="FOREACH" next="ORDENAR" %}
["Anakin", "Luke", "Rey"] {% include icon/pixel-plus.svg %} .map(conSable) {% include icon/pixel-plus.svg %} conSable ➜ jedi + usa ⚔️ {% include icon/pixel-plus.svg %} {% include icon/right.svg %} "Anakin" ➜ "Anakin usa ⚔️" {% include icon/right.svg %} "Luke" ➜ "Luke usa ⚔️" {% include icon/right.svg %} "Rey" ➜ "Rey usa ⚔️" {% include icon/pixel-plus.svg %} ["Anakin usa ⚔️", "Luke ...", "Rey ..."]
--

FOREACH: Recorrer un array

Este método recorre cada elemento del array y ejecuta una función ( callback ) a cada uno, sin crear un nuevo array.

Ejemplo:

```javascript run const plantas = ["🌵", "🌿", "🌷"]; function mostrar(item, index) { console.log(index, item); } // Recorrer cada elemento del arreglo plantas.forEach(mostrar); ```
{% include reveal/navigate.html up="MAP" down="REDUCE" next="ORDENAR" %}
["🌵", "🌿", "🌷"] {% include icon/pixel-plus.svg %} .forEach(mostrar) {% include icon/pixel-plus.svg %} mostrar ➜ index + item {% include icon/pixel-plus.svg %} "0 🌵" "1 🌿" "2 🌷"
--

REDUCE: Reducir todo a un valor acumulado

Este método recorre un array y lo reduce a un solo valor acumulando el resultado en cada iteración.

Ejemplo:

```javascript [] run const numeros = [10, 20, 30, 40]; const suma = numeros.reduce((acumulador, numero) => { return acumulador + numero; }, 0); console.log(suma); ```

Sort: Orden ascendente y descendente

Este método se utiliza para ordenar un array, ya sea en orden alfabético o numérico, modificando el array original según una función de comparación o el orden Unicode por defecto.

Ejemplo:

```javascript const numeros = [5, 120, 12, 1, 45]; numeros.sort((a, b) => b - a); console.log(numeros); ```
