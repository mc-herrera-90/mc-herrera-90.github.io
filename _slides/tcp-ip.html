¿Qué es TCP/IP?

TCP es un protocolo de comunicación que permite enviar información de forma segura y ordenada entre dispositivos conectados a Internet, asegurando que los datos lleguen correctamente. --- # ¿Qué significa TCP/IP?
## TCP

Transmission Control
Protocol

  • Garantiza el envío correcto de los datos.
  • Verifica errores.
  • Divide y reordena paquetes.
## IP

Internet
Protocol

  • Se encarga del direccionamiento.
  • Identifica origen y destino.
  • Dirige los paquetes al destino.
--- # Capas del Modelo TCP/IP

El modelo TCP/IP se compone de 4 capas. Es importante no confundirlo con el modelo OSI, ya que ambos organizan la red de forma distinta

-- # Capa 4: Aplicación

Es la capa más cercana al usuario y donde funcionan las aplicaciones que usamos diariamente, como navegadores web, correos electrónicos, videojuegos y plataformas de mensajería. Aquí se generan y reciben los datos que viajarán por la red.

-- # Capa 3: Transporte

Es la capa encargada de la transmisión de datos entre dispositivos, asegurando la entrega correcta y el control del flujo. Aquí operan protocolos como TCP y UDP.

-- # Capa 2: Internet

Es la capa encargada del direccionamiento y enrutamiento de los datos entre redes, utilizando direcciones IP para enviar la información hacia su destino.

-- # Capa 1: Acceso a red

Es la capa encargada de la transmisión de datos a través del medio físico o inalámbrico, incluyendo tecnologías como Ethernet, Wi-Fi, redes móviles (4G/5G) y enlaces satelitales.

--

El flujo de datos en el modelo TCP/IP comienza en la capa de Aplicación, desciende por Transporte e Internet, y finalmente llega a la capa de Acceso a la red para ser transmitido físicamente. En el destino, el proceso se invierte hasta llegar a la aplicación final.
