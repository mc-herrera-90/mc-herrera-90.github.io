¿Qué es YUMI?

YUMI ( _Your Universal Multiboot Installer_ ) es una herramienta que permite crear unidades USB booteables con múltiples sistemas operativos, ideal para probar diferentes sistemas operativos desde un solo dispositivo. -- Organiza múltiples sistemas operativos y herramientas en una sola memoria USB, permitiendo iniciarlos desde un menú al arrancar el equipo.
