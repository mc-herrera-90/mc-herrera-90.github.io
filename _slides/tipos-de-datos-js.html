Tipos de datos

--- ## ¿Qué es un tipo de dato? Un tipo de dato define el tipo de valor que una variable puede almacenar. Ejemplo: - Número - Texto - Verdadero/Falso --- ## Tipos de datos primitivos

Los más básicos en programación:

- Enteros (int) - Decimales (float / double) - Booleanos (true / false) - Caracteres (char) --- ## Números enteros
Se usan para contar o representar valores sin decimales.
### Ejemplo: \\[ 10,\ 25,\ -3,\ 0 \\] --- ## Números decimales
Permiten representar valores con punto decimal.
### Ejemplo: \\[ {\\color{#ff6b6b}3.14}, {\\color{#ff6b6b}2.5}, {\\color{#ff6b6b}-0.75} \\] --- ## Booleanos
Solo tienen dos valores posibles: true, false
### Ejemplo: ```javascript isActive = true isLogged = false ``` --- ## Texto (Strings) Representan cadenas de caracteres. Ejemplo: ```txt "Hola mundo" "Programación" ``` --- ## Tipos de datos compuestos Se forman a partir de otros tipos: * Arrays (arreglos) * Objetos * Listas * Diccionarios --- ## Arrays Colección de elementos del mismo tipo. Ejemplo: ```js [1, 2, 3, 4] ``` --- ## Objetos Estructuras con propiedades y valores. Ejemplo: ```js { nombre: "Marco", edad: 20 } ``` --- ## ¿Por qué son importantes? * Organizan la información * Permiten operaciones correctas * Mejoran la eficiencia del código
