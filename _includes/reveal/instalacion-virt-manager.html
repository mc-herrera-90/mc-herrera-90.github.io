¿Qué es y por qué usar Virt Manager?

Es una interfaz de escritorio para entornos Linux que permite administrar máquinas virtuales mediante KVM, QEMU y libvirt. Se utiliza porque facilita la gestión de máquinas virtuales a través de una interfaz gráfica, evitando el uso exclusivo de la terminal y permitiendo configurar recursos, redes, almacenamiento y snapshots de forma sencilla. --

Instalación de Virt Manager

#### En Ubuntu / Debian #### En Fedora / RHEL / CentOS
```bash sudo apt update && sudo apt upgrade sudo apt install virt-manager ``` ```bash sudo dnf update sudo dnf install virt-manager ```

Habilitar el servicio de virtualización

#### En Ubuntu / Debian #### En Fedora / RHEL / CentOS
```bash sudo systemctl enable --now libvirtd ``` ```bash sudo systemctl enable --now libvirtd ```

Solución

Esto ocurre porque el usuario aún no tiene permisos para acceder al servicio. Para solucionarlo ejecuta el siguiente comando: ```bash sudo usermod -aG libvirt $USER sudo usermod -aG kvm $USER ``` Luego, cierra sesión y vuelve a entrar o reinicia el sistema -- ### Crear una nueva máquina virtual Al entrar nuevamente a __virt-manager__, continua con el proceso de crear una nueva máquina virtual:
