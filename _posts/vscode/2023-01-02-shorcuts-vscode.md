## Funcionalidad Básica

{% tabs shorcuts_1 %}
{% tab shorcuts_1 Windows/Linux %}
| Combinación                                       | Descripción                                                   |
| ------------------------------------------------- | ------------------------------------------------------------- |
| <kbd>Ctrl</kbd> + <kbd>Shift</kbd> + <kbd>N</kbd> | Abre una nueva instancia de Visual Studio Code.               |
| <kbd>Ctrl</kbd> + <kbd>N</kbd>                    | Crea un nuevo archivo sin guardar.                            |
| <kbd>Ctrl</kbd> + <kbd>S</kbd>                    | Guarda el archivo.                                            |
| <kbd>Ctrl</kbd> + <kbd>Shift</kbd> + <kbd>S</kbd> | Realiza la acción «Guardar como».                             |
| <kbd>Ctrl</kbd> + <kbd>O</kbd>                    | Abre un archivo desde el explorador de archivos.              |
| <kbd>Ctrl</kbd> + <kbd>Shift</kbd> + <kbd>W</kbd> | Cierra la instancia actual de Visual Studio Code.             |
| <kbd>Ctrl</kbd> + <kbd>B</kbd>                    | Activa o desactiva la visibilidad de la barra lateral.        |
| <kbd>Ctrl</kbd> + <kbd>Shift</kbd> + <kbd>P</kbd> | Abre la paleta de comandos. También puede usar <kbd>F1</kbd>. |
| <kbd>Ctrl</kbd> + <kbd>Shift</kbd> + <kbd>X</kbd> | Cambia al panel de extensiones.                               |
| <kbd>Ctrl</kbd> + <kbd>Shift</kbd> + <kbd>E</kbd> | Cambia al panel del explorador de archivos.                   |
| <kbd>Ctrl</kbd> + <kbd>Shift</kbd> + <kbd>D</kbd> | Cambia al panel de depuración.                                |
| <kbd>Ctrl</kbd> + <kbd>Shift</kbd> + <kbd>G</kbd> | Cambia al panel de control de código fuente.                  |
{% endtab %}

## Selección múltiple y cursores


{% tabs shorcuts_cursores %}
{% tab shorcuts_cursores Windows/Linux %}
| Combinación                                          | Descripción                                                               |
| ---------------------------------------------------- | ------------------------------------------------------------------------- |
| <kbd>Ctrl</kbd> + <kbd>A</kbd>                       | Selecciona todo el texto.                                                 |
| <kbd>Ctrl</kbd> + <kbd>L</kbd>                       | Selecciona la línea actual.                                               |
| <kbd>Ctrl</kbd> + <kbd>Shift</kbd> + <kbd>L</kbd>    | Selecciona todas las instancias de la selección actual.                   |
| <kbd>Ctrl</kbd> + <kbd>F2</kbd>                      | Selecciona todas las coincidencias de la palabra actual.                  |
| <kbd>Ctrl</kbd> + <kbd>D</kbd>                       | Agrega a la selección la siguiente ocurrencia (si se vuelve a presionar). |
| <kbd>Shift</kbd> + <kbd>Alt</kbd> + <kbd>Right</kbd> | Amplía la selección.                                                      |
| <kbd>Shift</kbd> + <kbd>Alt</kbd> + <kbd>Left</kbd>  | Reduce la selección.                                                      |
| <kbd>Alt</kbd> + clic                                | Inserta un cursor adicional.                                              |
| <kbd>Ctrl</kbd> + <kbd>Alt</kbd> + <kbd>Up</kbd>     | Inserta un cursor encima de la fila actual.                               |
| <kbd>Ctrl</kbd> + <kbd>Alt</kbd> + <kbd>Down</kbd>   | Inserta un cursor debajo de la fila actual.                               |
| <kbd>Ctrl</kbd> + <kbd>U</kbd>                       | Deshace el último cursor.                                                 |

{% endtab %}
